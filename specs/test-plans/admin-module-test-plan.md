# OrangeHRM 管理モジュール - 総合テスト計画書

## アプリケーション概要

OrangeHRM 5.7の管理モジュールは、システム全体の設定と組織構造を管理するための中核機能を提供します。このモジュールでは以下の主要機能が利用できます:

- **ユーザー管理**: システムユーザーの追加、編集、削除、権限管理
- **職務設定**: 職位、給与等級、雇用ステータス、職種カテゴリ、勤務シフトの管理
- **組織構造**: 会社情報、拠点、組織階層の設定
- **資格情報**: スキル、学歴、ライセンス、言語、会員資格の管理
- **国籍管理**: 国籍情報の追加、編集、削除
- **企業ブランディング**: 企業ロゴやブランディング設定
- **システム設定**: メール設定、ローカライゼーション、モジュール表示設定

### アクセス情報
- **URL**: http://localhost:8080
- **管理者ユーザー名**: Admin
- **管理者パスワード**: Admin#0630#

### モジュール構成
管理モジュールは以下のサブメニューで構成されています:

1. **User Management (ユーザー管理)**
   - Users (ユーザー)

2. **Job (職務)**
   - Job Titles (職位)
   - Pay Grades (給与等級)
   - Employment Status (雇用ステータス)
   - Job Categories (職種カテゴリ)
   - Work Shifts (勤務シフト)

3. **Organization (組織)**
   - General Information (一般情報)
   - Locations (拠点)
   - Structure (組織構造)

4. **Qualifications (資格)**
   - Skills (スキル)
   - Education (学歴)
   - Licenses (ライセンス)
   - Languages (言語)
   - Memberships (会員資格)

5. **Nationalities (国籍)**

6. **Corporate Branding (企業ブランディング)**

7. **Configuration (設定)**
   - Email Configuration (メール設定)
   - Email Subscriptions (メール購読)
   - Localization (ローカライゼーション)
   - Language Packages (言語パッケージ)
   - Modules (モジュール)
   - Social Media Authentication (ソーシャルメディア認証)
   - Register OAuth Client (OAuth クライアント登録)
   - LDAP Configuration (LDAP設定)

## テストシナリオ

### 1. ユーザー管理

**前提条件**: `tests/admin-seed.spec.ts`

#### 1.1 新規ユーザーの追加（正常系）

**手順**:
1. 左サイドバーの「Admin」をクリック
2. トップメニューの「User Management」をクリック
3. ドロップダウンから「Users」を選択
4. 「Add」ボタンをクリック
5. 「User Role」ドロップダウンから「Admin」を選択
6. 「Employee Name」フィールドに「Admin User」と入力（オートコンプリート）
7. 「Status」ドロップダウンから「Enabled」を選択
8. 「Username」フィールドに「testuser001」と入力
9. 「Password」フィールドに「Test@1234」と入力
10. 「Confirm Password」フィールドに「Test@1234」と入力
11. 「Save」ボタンをクリック

**期待結果**:
- ユーザーが正常に追加される
- System Usersリストページにリダイレクトされる
- 成功メッセージが表示される
- 新規ユーザー「testuser001」がテーブルに表示される
- ユーザー情報が正しく保存される（Username: testuser001, User Role: Admin, Status: Enabled）

#### 1.2 必須フィールドのバリデーション

**手順**:
1. Admin >> User Management >> Users >> Add に移動
2. すべてのフィールドを空欄のまま「Save」ボタンをクリック

**期待結果**:
- フォームが送信されない
- 必須フィールド（User Role、Employee Name、Status、Username、Password、Confirm Password）にエラーメッセージが表示される
- エラーメッセージ: "Required" が各必須フィールドに表示される

#### 1.3 パスワード不一致のバリデーション

**手順**:
1. Admin >> User Management >> Users >> Add に移動
2. User Role: 「Admin」を選択
3. Employee Name: 「Admin User」と入力
4. Status: 「Enabled」を選択
5. Username: 「testuser002」と入力
6. Password: 「Test@1234」と入力
7. Confirm Password: 「Test@5678」と入力（異なるパスワード）
8. 「Save」ボタンをクリック

**期待結果**:
- フォームが送信されない
- Confirm Passwordフィールドにエラーメッセージが表示される
- エラーメッセージ: "Passwords do not match" が表示される

#### 1.4 重複ユーザー名のバリデーション

**手順**:
1. Admin >> User Management >> Users >> Add に移動
2. User Role: 「ESS」を選択
3. Employee Name: 「Admin User」と入力
4. Status: 「Enabled」を選択
5. Username: 「admin」と入力（既存のユーザー名）
6. Password: 「Test@1234」と入力
7. Confirm Password: 「Test@1234」と入力
8. 「Save」ボタンをクリック

**期待結果**:
- フォームが送信されない
- Usernameフィールドにエラーメッセージが表示される
- エラーメッセージ: "Username already exists" または同等のメッセージが表示される

#### 1.5 ユーザーの編集

**手順**:
1. Admin >> User Management >> Users に移動
2. ユーザーリストから編集するユーザーの「Edit」アイコン（鉛筆マーク）をクリック
3. Status: 「Disabled」に変更
4. 「Save」ボタンをクリック

**期待結果**:
- ユーザー情報が正常に更新される
- System Usersリストページにリダイレクトされる
- 成功メッセージが表示される
- 更新されたユーザーのStatusが「Disabled」に変更されている

#### 1.6 ユーザーの検索

**手順**:
1. Admin >> User Management >> Users に移動
2. Username フィールドに「admin」と入力
3. 「Search」ボタンをクリック

**期待結果**:
- 検索結果がフィルタリングされる
- "admin"を含むユーザーのみがテーブルに表示される
- レコード数が更新される（例: "(1) Record Found"）

#### 1.7 ユーザー検索のリセット

**手順**:
1. Admin >> User Management >> Users に移動
2. Username フィールドに「test」と入力
3. 「Search」ボタンをクリック
4. 「Reset」ボタンをクリック

**期待結果**:
- すべての検索フィールドがクリアされる
- すべてのユーザーがテーブルに表示される
- レコード数が全体数に戻る

#### 1.8 ユーザーの削除

**手順**:
1. Admin >> User Management >> Users に移動
2. 削除するユーザーの「Delete」アイコン（ゴミ箱マーク）をクリック
3. 確認ダイアログで「Yes, Delete」をクリック

**期待結果**:

- 「Yes, Delete」をクリックするとユーザーが削除される
- 成功メッセージが表示される
- 削除されたユーザーがリストから消える

2. 削除する複数のユーザーのチェックボックスを選択
3. テーブルヘッダーの削除アイコンをクリック
4. 確認ダイアログで「Yes, Delete」をクリック

**期待結果**:
- 選択したすべてのユーザーが削除される
- 成功メッセージが表示される
- 削除されたユーザーがリストから消える

#### 1.10 ユーザー追加のキャンセル

**手順**:
1. Admin >> User Management >> Users >> Add に移動
2. 任意のフィールドに値を入力
3. 「Cancel」ボタンをクリック

**期待結果**:
